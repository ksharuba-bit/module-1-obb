## Завдання

1. Визначити принцип ООП — інкапсуляцію.
2. Проаналізувати особливості перевантаження операторів відношення та логічних операторів.
3. Реалізувати віртуальну функцію `func()`:
   - у базовому класі `base` вона виводить значення `i`;
   - у `derived1` виводить квадрат `i`;
   - у `derived2` функція не перевизначається.

## Результат роботи програми

```text
base::func() -> i = 10
derived1::func() -> i^2 = 100
base::func() -> i = 10
```

## Компіляція

```bash
g++ -std=c++17 main.cpp -o variant17
./variant17
```

## Що демонструє програма

Програма демонструє:
- успадкування;
- віртуальні функції;
- перевизначення методів;
- динамічний поліморфізм;
- виклик базової реалізації, якщо метод у похідному класі не перевизначено.
